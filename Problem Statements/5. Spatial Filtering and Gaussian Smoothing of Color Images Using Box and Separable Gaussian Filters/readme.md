# Image Filtering with Box and Separable Gaussian Filters

##  Overview
This project demonstrates the application of **box filtering** and **separable Gaussian filtering** using OpenCV and NumPy.  
It compares normalized vs. unnormalized kernels and shows how different kernel sizes affect image smoothing.

##  Requirements
Make sure you have the following installed:
- Python 3.x
- NumPy
- OpenCV (`cv2`)
- Matplotlib

You can install dependencies with:
```bash
pip install numpy opencv-python matplotlib
